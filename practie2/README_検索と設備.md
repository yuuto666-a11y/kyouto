# 略称検索・トイレ・AED表示の使い方

## 起動方法

`practie2/` の中で `pip install -r requirements.txt` → `python app.py` と実行し、ブラウザで `http://127.0.0.1:5000/` を開きます。

## CSVを編集する場所

`static/campus_info.csv` が実際に読み込まれるファイルです。UTF-8（BOM付き）で保存してあります。

- `建物ID`: 建物の場合は地図の `buildings.json` の `name` と一致させます。
- `正式名称`、`略称`、`検索ワード`: いずれも検索対象。`検索ワード` はカンマ区切りで増やせます。
- `種別`: `建物`、`トイレ`、`AED` のいずれか。
- `設置階`: 分かる場合のみ記載（不明な場合は空欄にする）。
- `対象建物ID`: トイレやAEDについて、どの建物のそばにピンを置くかを指定します。
- `補足`: ピンを押した時の説明。
- `情報源`: 確認に使用した参照先URL。

CSVに追記・修正してページを再読み込みすると検索候補・設備表示に反映されます。**建物名だけのデータでは設備の新しいピンは生まれないため、設備は必ず `種別` と `対象建物ID` を指定**してください。

## 検索例

`アカリン` → アカデミックリンクス / `1号館` → 清和館 / `みかん` → mican / `AED` → AEDのある建物のピンを表示 / `トイレ` → バリアフリートイレのある建物を表示 / `AED H` → アカデミックリンクスのAED情報。

## 表示位置の注意

トイレは**大学公開図に掲載されているバリアフリートイレの一部**を登録しています。一般トイレ全体を登録したものではありません。AEDも建物付近に表示した概略ピンで、建物の出入口や機器の正確な位置を示すものではありません。**必ず最新の学内表示や管理者の案内で確認してください。**

## 2026年10月 追加機能（トイレの種類分け）

- トイレを 🚻「一般トイレ」と ♿「バリアフリートイレ」に区別しました。AEDは従来通りです。
- 旧CSVの種別 `トイレ` は ♿「バリアフリートイレ」として認識します。
- CSVの `確認状況` を追加。一般トイレの23件は**入力ひな形（未確認）**です。未確認データは検索候補や地図ピンに表示しません。
- 一般トイレの設置場所は公開大学地図だけでは確認できませんでした。現地調査・フロア図等で建物と階が確認できたら `確認状況` を `確認済み` に変更してください（種別は `一般トイレ` のまま）。その後ページ再読込で 🚻 ピンが有効になります。
- 検索「トイレ」は両方を、検索「一般トイレ」「🚻」は一般、検索「バリアフリートイレ」「♿」はバリアフリーだけを表示します。
- バスは**ローカルに埋め込まれた時刻表**をもとにした予想表示です。更新されるのは次便と残り時間であり、公式時刻表の自動取得・リアルタイム遅延取得ではありません。公式時刻表へのリンクを追加しました。
